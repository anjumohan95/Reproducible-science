#Reproducible-science
Assignment BIO 415
made by Anju Mohan
This project was made to 
 build multiple regression models
• check for variance inflation in a model
• compare models using partial F-tests
• interpret standardized regression coefficients
to run this project you have to install R and R studio, you can do herehttps://cran.r-project.org/bin/windows/base/ 
you will also need the packages car,ggally,performace,ggplot2,readr
dplyr,tidyr which is prepared in the script provided the dataset WOLFPUPS.CSV can be found in the github directory.

#How to reproduce
Please clone or download this repository
open Reproducible-science.Rproj and install the R packages
Run the code entirely
